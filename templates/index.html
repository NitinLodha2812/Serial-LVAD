Instructions

1. Load a raw data file (.txt or .csv comma-delimited).
2. The CA tab lets you select a 5-minute window and compute MX index.
3. The CVR tab lets you select baseline (~32 s) and hypercapnia (~10 s) windows, detect peak etCO2, and compute CVR.
4. Choose MCA or PCA vessel before calculating. Repeat for both.
5. Save results as a unified Excel workbook or JSON progress file.
